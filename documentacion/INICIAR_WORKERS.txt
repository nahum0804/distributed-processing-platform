INICIAR LOS WORKERS (worker.py)
==============================

Servidor Central (Nahum):  100.122.10.52:8000
Worker de Kenny (Linux):   100.118.70.69

QUE HACE EL WORKER
- Pide una tarea al servidor, PROCESA el archivo con FFmpeg y reporta:
    mp4       -> transcode_video  (video H.264 + AAC)
    mp3, wav  -> convert_audio    (MP3)
- Los resultados quedan en la carpeta resultados_worker/ (una carpeta por tarea).
- Si un archivo no esta en su --dataset-dir, la tarea se reporta como fallida
  (antes se marcaba exitosa sin procesar nada).
- Con --simulate solo espera unos segundos, sin FFmpeg (como antes).

REQUISITOS EN CADA MAQUINA WORKER
1. Tailscale activo y con sesion iniciada en la misma cuenta del servidor.
2. FFmpeg instalado (comprobar con:  ffmpeg -version).
3. Una copia local del dataset (los mismos archivos que el servidor sembro).
   La estructura de carpetas puede ser distinta: el worker busca por nombre.

Orden recomendado:
  1. El servidor ya esta iniciado (REINICIAR_SERVIDOR.txt).
  2. Iniciar TODOS los workers con este archivo.
  3. Recien entonces sembrar o reiniciar la cola (REINICIAR_SERVIDOR.txt).

IMPORTANTE
- Copiar los comandos de este archivo, no del PDF (el PDF parte las lineas).
- Cada comando de worker va en UNA sola linea.
- Cada worker necesita un --worker-id distinto.
- Las lineas que empiezan con # son comentarios.

-----------------------------------------------------
PRUEBAS OPCIONALES DE TOLERANCIA A FALLOS
-----------------------------------------------------

# 1) Worker caido: detener un worker con Ctrl + C mientras procesa.
#    A los 5 minutos (300 s) la tarea vuelve a "pending" y otro worker la toma:
curl http://100.122.10.52:8000/tasks/status

# 2) Fallos simulados: agregar --simulate-failures al comando del worker.
#    Falla ~15 % de las tareas; tras 3 fallos una tarea queda en "failed".
.venv/bin/python worker.py --server http://100.122.10.52:8000 --worker-id laptop-kenny-fallos --dataset-dir dataset/real --simulate-failures


-----------------------------------------------------
SI ALGO FALLA
-----------------------------------------------------
- Al arrancar dice "No se encontró ffmpeg": instalar FFmpeg (paso 2) o usar
  --simulate.
- Al arrancar dice "La carpeta del dataset no existe": corregir --dataset-dir.
- "No se pudo conectar con el servidor central": Tailscale apagado en
  alguna maquina, o el servidor no esta corriendo.
- "Sin tareas pendientes" todo el tiempo: la cola esta vacia o ya se
  consumio. Revisar /tasks/status; si "pending" es 0, reiniciar la cola con
  el METODO A de REINICIAR_SERVIDOR.txt (seed_tasks.py ... --reset).
- Tareas fallidas con "Archivo no encontrado en --dataset-dir": esa maquina
  no tiene una copia de ese archivo del dataset.
- "error: argument --dataset-dir: expected one argument": el comando se
  partio en dos lineas al copiarlo. Pegarlo en una sola linea.
